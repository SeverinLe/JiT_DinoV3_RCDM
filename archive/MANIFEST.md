# Archive Manifest

Record of every artifact removed from the working tree during the 2026-08-03 repository
restructure (branch `repo-restructure`). Nothing here is lost work: **all source code and
notebooks are preserved in `archive/scripts/` and `archive/notebooks/`**, and every deleted
model checkpoint is identified below by its W&B run so it can be re-downloaded.

The user additionally holds a full offline duplicate of the pre-restructure project.
